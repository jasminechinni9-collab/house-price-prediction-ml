# House Price Prediction using Machine Learning

## Project Overview
This project predicts house sale prices using Machine Learning algorithms. The goal is to estimate house prices based on different property features.

## Dataset
- 1,460 records
- 79 input features
- Target variable: SalePrice

The dataset file should be named `data.csv`.

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- XGBoost
- LightGBM

## Project Workflow
1. Data Loading
2. Data Cleaning
3. Exploratory Data Analysis (EDA)
4. Missing Value Handling
5. Feature Engineering
6. Categorical Encoding
7. Feature Transformation
8. Feature Scaling
9. Model Building
10. Hyperparameter Tuning
11. Model Evaluation

## Machine Learning Models
- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor
- XGBoost Regressor
- LightGBM Regressor

## Best Performing Model
Tuned XGBoost Regressor.

Model performance is evaluated using:
- R² Score
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)

Refer to the notebook for the final evaluation results.

## How to Run
1. Download or clone this repository.
2. Open the notebook using Google Colab or Jupyter Notebook.
3. Upload the dataset as `data.csv`.
4. Update the dataset path if required.
5. Run all cells in order.

## Conclusion
This project demonstrates an end-to-end Machine Learning workflow for predicting house prices, including data preprocessing, exploratory data analysis, model training, hyperparameter tuning, and evaluation.
